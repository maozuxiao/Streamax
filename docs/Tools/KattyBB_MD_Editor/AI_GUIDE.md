# AI 功能使用说明

编辑器内置了 AI 辅助写作：选中一段文字，即可让 AI 帮你重写、润色、精简、扩写、纠错或翻译。

---

## 一、安装配套扩展（推荐）

浏览器里的网页**无法直连** OpenAI、DeepSeek、智谱、Moonshot 等供应商——它们都没有开放 CORS。配套扩展 `Katty AI Bridge` 把发请求这件事挪到了浏览器的扩展层，从而绕开这个限制，并且 Key 只存在扩展里，页面拿不到。

1. 打开 `chrome://extensions/`，右上角打开**开发者模式**
2. 点**「加载已解压的扩展程序」**，选择 `katty-ai-bridge` 目录
3. 点扩展图标 → **打开完整设置**，选一家供应商、填 Key、选模型，再点**授权跨域**和**测试连接**

装好即可，本编辑器会自动检测到它。

> 本地双击打开 HTML（`file://`）调试时，还需到 `chrome://extensions/` 进入本扩展的「详细信息」，打开**「允许访问文件网址」**，并把 `file://` 加进白名单。

## 二、怎么用

**方式一：选中即用**

在编辑器里选中一段文字 → 光标旁浮出指令条 → 点「润色」等指令 → 生成完毕后弹出并排对比 → 确认替换。

**方式二：多轮对话**

点指令条上的**「对话」**，或点工具栏的 **AI** 按钮打开右侧面板。选中内容会作为上下文，你可以继续追问「再正式一点」「换个说法」，满意后再点消息下方的**「应用到文档…」**。

生成过程中可随时按停止按钮中断。

## 三、没有扩展也能用（功能受限）

未检测到扩展时，会自动降级为**直连**。这时需要点 AI 面板的设置按钮，自己填 API 地址、Key 和模型。

直连只对**开放了 CORS 的供应商**有效，例如 OpenRouter。OpenAI / DeepSeek / 智谱 / Moonshot / Anthropic 一律不行。

⚠ 直连时 Key 会**明文存在浏览器的 localStorage** 中。如果介意，请安装扩展。

## 四、常见问题

**工具栏 AI 按钮上有橙点**
表示通道不可用或未配置。点 AI 按钮打开面板 → 设置，可以看到具体原因。

**装完扩展后仍显示「AI 不可用」**
先刷新页面（F5）——已在打开状态的标签页感知不到新装的扩展。还不行就点设置里的**「重新检测」**；页面切换回来时也会自动重试。

**提示「站点不在信任列表中」**
扩展默认只信任 `https://maozuxiao.github.io`。到扩展设置页的「站点白名单」里把当前访问的来源加进去。

本地用 `http://localhost:8765` 这类地址预览时，建议直接添加 `http://localhost:*`（匹配任意端口），这样换端口也不用重新配。改完白名单**刷新一下页面**即可，不必重载扩展。

**提示缺少跨域权限**
到扩展设置页点**「授权跨域」**，Chrome 会弹窗确认。

**生成到一半中断**
单次请求上限 60 秒。长文本建议分段处理。

**替换后想反悔**
正常按 Ctrl+Z 即可，一次撤销正好回到替换前。

## 五、给开发者：在别的静态页里复用

扩展是与编辑器解耦的独立项目。任何静态网页只要引入 `js/ai-bridge.js`（零依赖，单文件），就能用同一套 API：

```html
<script src="js/ai-bridge.js"></script>
```

```js
KattyAI.probe().then(info => console.log(info.mode))   // 'extension' | 'direct' | 'none'

KattyAI.chat({
  messages: [{ role: 'user', content: '你好' }],
  onDelta: (chunk, full) => console.log(chunk)
}).then(text => console.log(text))
```

扩展的弹出面板里有**「复制页面接入 SDK」**按钮，可直接拿到源码。完整协议与消息格式见 `katty-ai-bridge/README.md`。
